# Site institucional 03

Estudo de site institucional com páginas PHP e formulário de contato processado no servidor.

## Tecnologias

- PHP
- HTML
- CSS
- JavaScript

## Funcionalidades e utilização

Execute php -S localhost:8000 -t site-03 e abra http://localhost:8000. Revise/rotacione a possível credencial no código de contato antes de utilizar a integração.

## Como executar

```bash
git clone https://github.com/EuGeanCarlos/site-03.git
cd site-03
```

Execute php -S localhost:8000 -t site-03 e abra http://localhost:8000. Revise/rotacione a possível credencial no código de contato antes de utilizar a integração.
